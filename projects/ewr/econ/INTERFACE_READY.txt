1) BUY  (run AS the buyer, at the buyer):
   execute as <buyer> at @s run function ewr_econ:try_buy {price:<int>, item:"<text>", then:"<namespace:function>"}
   example:
   function ewr_econ:try_buy {price:150, item:"Flight ticket to Terminal C", then:"ewr_staff:sell/ticket_c"}

   - ewr_infinite OR money >= price: deducts price (not for infinite), actionbar "Bought <item> for $<price>" (green),
     then runs `function <then>` as/at the buyer, and try_buy returns 1.
   - otherwise: red actionbar "Not enough money: <item> costs $<price>, you have $<money>", runs nothing, returns fail (0).
   - You can test the result: execute store success score #x obj run function ewr_econ:try_buy {...}
     or: execute if function ewr_econ:try_buy {...} run ...   (note: that form runs `then` too)
   Rules: price is a plain int (no commas). item must not contain " or \ characters.
          `then` must be a NON-macro function id (it is called with no arguments).
          From inside your own macro you may write:
          $function ewr_econ:try_buy {price:$(price), item:"$(item)", then:"$(then)"}
